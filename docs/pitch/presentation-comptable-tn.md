# ⁧برنامج لتسيير الشركات العقارية⁩

⁧*ورقة نحب نقدّملك بيها المشروع اللي نخدم عليه*⁩

------------------------------------------------------------------------

## ⁧1. الفكرة في جملة⁩

⁧برنامج تخدم بيه الشركة العقارية كل حاجة في بلاصة وحدة: العقارات، الكرا، الخلاص، الأشغال والبيع. وأرقامها تتفسّر وتتثبّت وتتصدّر للـ comptabilité.⁩

------------------------------------------------------------------------

## ⁧2. المشكل⁩

⁧برشا شركات عقارية المعلومة عندها مشتّتة: Excel، ورق، تليفونات، ميساجات. وفي آخر الشهر تلقى: كرا ما تفكّرناش نطلبوه، شيكات حد ما يعرف وين وصلت، relevé متاع المالك يتعمل بالإيد، والـ comptable يرجع يركّب الأرقام من الصفر.⁩

------------------------------------------------------------------------

## ⁧3. حكاية بسيطة⁩

⁧*شركة "Médina Immobilier" عندها شقة A1 تكريها.*⁩

1.  ⁧**أول الشهر**: البرنامج يحضّر facture الكرا وحدو من العقد (bail).⁩
2.  ⁧**الـ locataire يخلّص بشيك**: البرنامج يتبع الشيك (تسلّمناه، تحطّ في البنك، تخلّصت ولا رجعت impayé)، يربطو بالfacture الصحيحة ويعمل reçu.⁩
3.  ⁧**يجي السبّاك**: المصروف متاع 300 دينار يتسجّل على الشقة، مع facture السبّاك، ونحدّدو شكون يتحمّلو: المالك، الـ locataire ولا الشركة.⁩
4.  ⁧**في آخر الشهر**: البرنامج يحضّر relevé المالك:⁩

    > ⁧الكرا اللي تقبض − المصاريف − أتعاب الشركة (honoraires) = اللي لازم يتعطى للمالك⁩

    ⁧*مثال باش نصلحوه مع بعضنا:* 900 − 300 − 72 (أتعاب 8%) = **528 دينار**.⁩
5.  ⁧**الدفعة للمالك** تتسجّل. والشهر **يتسكّر**: حتى واحد ما يعاود يبدّل في أرقامو.⁩
6.  ⁧**إنت كـ comptable** تعمل export لـ Excel بالfactures والخلاص والمصاريف متاع الفترة.⁩

------------------------------------------------------------------------

## ⁧4. شنوة يعمل البرنامج⁩

| ⁧المجال⁩ | ⁧شنوة تنجم تعمل الشركة⁩ |
|---|---|
| ⁧**العقارات**⁩ | ⁧تسجّل العمارات، الدور، الشقق، المكاتب، المحلات، الباركينغ، وتتبع حالتها وتاريخها.⁩ |
| ⁧**المالكين**⁩ | ⁧الفيشات، الحصص (الورثة، المشتركين)، mandat de gestion مع الأتعاب لكل عقار، وتاريخ تبديل المالك.⁩ |
| ⁧**الـ locataires والعقود**⁩ | ⁧العقد (bail)، الكرا وتاريخ تبديلو، dépôt de garantie، الضامنين، état des lieux دخول وخروج، التجديد، نهاية العقد، متابعة تسجيل العقد، وطلبات الكرا.⁩ |
| ⁧**الفلوس**⁩ | ⁧factures الكرا، الخلاص (كاش، شيك، virement)، متابعة الشيكات، reçus، impayés، avoirs، remboursements، رزنامة خلاص للدين، مقارنة الخلاص بكشف البنك، تسكير الشهر، وexport للـ comptable.⁩ |
| ⁧**المصاريف والـ relevés**⁩ | ⁧المصاريف لكل عقار وشكون يتحمّلها، الوثائق المرفقة، relevés المالكين، الدفعات للمالكين، ومداخيل الشركة (أتعاب وعمولات).⁩ |
| ⁧**الأشغال والمزوّدين**⁩ | ⁧طلبات التدخّل، الأشغال، المواد والساعات، والكلفة تولّي مصروف. المزوّدين مع وثائقهم وتواريخ صلاحيتها (assurance، CNSS، attestation fiscale)، devis، factures وخلاص.⁩ |
| ⁧**البيع**⁩ | ⁧عرض للبيع، المهتمين، الزيارات، العروض، الحجز بعربون (arbon)، رزنامة الدفع، دفعات المشتري، العمولة، وإبرام البيع: المشتري يولّي مالك. وبيع عقار مكرّي.⁩ |
| ⁧**الـ syndic (الأساسيات)**⁩ | ⁧مصاريف العمارة، حصة كل مالك، وخزينة العمارة.⁩ |
| ⁧**أمن العمارات**⁩ | ⁧الحوادث، الزوّار، دورات الحراسة، والمفاتيح.⁩ |

⁧كل موظف عندو واجهتو ويشوف غير اللي يخصّو: التقني ما يشوف حتى مبلغ، والـ comptable متاع الشركة يشوف كل الفلوس. وداتا كل شركة مفصولة على الباقي.⁩

------------------------------------------------------------------------

## ⁧5. علاش تطمّن⁩

-   ⁧**حتى حاجة ما تتمسح.** الغلطة تتصلّح بكتابة جديدة (avoir، remboursement) والقديمة تبقى باينة.⁩
-   ⁧**كل حركة تتسجّل**: شكون عمل شنوة وإمتى.⁩
-   ⁧**الشهر المسكّر مقفّل.**⁩
-   ⁧**كل رقم يتفسّر**: أنهي خلاص سدّد أنهي facture، وأنهي مصروف على أنهي مالك.⁩
-   ⁧**الـ exports لـ Excel** موجودين ليك.⁩

------------------------------------------------------------------------

## ⁧6. شنوة نحب منك⁩

⁧موش باش توافق على برنامج. نحب نستفيد من **خبرتك في الميدان** باش البرنامج يطبّق القواعد الصحيحة:⁩

-   ⁧**قواعد الحساب**: الأتعاب، relevés المالكين، العمولات، dépôts، العربون.⁩
-   ⁧**الضرائب**: أنهي ضريبة تتطبّق على أنهي عملية.⁩
-   ⁧**النقاط القانونية** اللي لازم نحترموها.⁩
-   ⁧**الحدود**: وين يوقف البرنامج، وين تبدا comptabilité متاعك.⁩
-   ⁧**حاجتك إنت**: شنوة تحتاج باش ما تعاودش تكتب الحاجة مرتين.⁩

------------------------------------------------------------------------

## ⁧7. ورقة الأسئلة⁩

| ⁧الرقم⁩ | ⁧السؤال⁩ | ⁧جوابك⁩ |
|---|---|---|
| | ⁧**الحساب**⁩ | |
| 1 | ⁧أتعاب التسيير (honoraires): على أنهي أساس (الكرا المقبوض ولا المفوتر، HT ولا TTC) وبأنهي نسبة حسب نوع العقار؟⁩ | |
| 2 | ⁧relevé المالك (الكرا − المصاريف − الأتعاب): هذا الحساب صحيح؟ شنوة لازم نزيدو ولا ننقصو؟⁩ | |
| 3 | ⁧المصاريف: وقتاش يتحمّلها المالك، وقتاش الـ locataire، وقتاش الشركة؟⁩ | |
| 4 | ⁧عمولة البيع بالتوكيل (mandat): كيفاش تتحسب ووقتاش تولّي مستحقة؟⁩ | |
| | ⁧**الضرائب**⁩ | |
| 5 | ⁧TVA: أنهي كراءات وأتعاب وعمولات تدخل فيها؟⁩ | |
| 6 | ⁧retenue à la source: في أنهي حالات تتطبّق ومن يخلّصها؟⁩ | |
| 7 | ⁧facturation électronique وترقيم الfactures والreçus: شنوة الواجبات؟⁩ | |
| | ⁧**القانون**⁩ | |
| 8 | ⁧تسجيل عقد الكرا في القباضة: شنوة الأجل (60 يوم؟) والوثائق اللي لازم نحتفظو بيها؟⁩ | |
| 9 | ⁧dépôt de garantie: وقتاش نجم نخصم منو وقتاش نرجّعو؟⁩ | |
| 10 | ⁧العربون (arbon) متاع الحجز: يتسترجع ولا لا كان البيعة تلغات؟⁩ | |
| 11 | ⁧التثبّت من هوية المشتري (قاعدة مكافحة تبييض الأموال متاع جانفي 2026): شنوة لازم نجمعو ونحتفظو؟⁩ | |
| 12 | ⁧قداش من وقت نحتفظو بالعقود، الfactures، بطاقات التعريف، والحوايج اللي خلّاها locataire قديم؟⁩ | |
| | ⁧**الحدود والتبادل**⁩ | |
| 13 | ⁧وين يوقف البرنامج وين تبدا comptabilité متاعك؟ لازم نطلّعو écritures ولا غير exports؟⁩ | |
| 14 | ⁧أنهي format export يعجبك (Excel، CSV ولا آخر) وبأنهي colonnes؟⁩ | |
| 15 | ⁧الشيك اللي رجع impayé وfrais البنك: كيفاش نتعاملو معاهم؟⁩ | |
| 16 | ⁧charges d'immeuble (syndic): فما قواعد خاصة لازم نحترموها؟⁩ | |
